Overview

Project Overview

Petoriz is a consumer mobile application designed to simplify pet parenthood by merging commercial product shopping with veterinary and grooming appointment scheduling. The platform allows pet owners to purchase diet products and medications, discover nearby pet care clinics on interactive maps, book confirmed service slots, and receive automated vaccination and care reminders.

Product Context & Objectives

Pet owners traditionally navigate disjointed platforms for buying supplies versus scheduling clinic visits. Petoriz unified these distinct user journeys into a cohesive mobile interface, requiring a synchronized state architecture capable of handling physical product shipping logistics alongside digital appointment calendar bookings.

Architecture

State Management & Offline Data Strategy

GetX Reactive Architecture

The application leverages GetX controllers bound to specific feature lifecycles (`CartController`, `AppointmentController`, `PetProfileController`). Observables (`RxList`, `RxBool`) ensure reactive UI recalculations for cart totals, shipping rates, and slot availability without manual `setState` propagation.

Persistent data such as active carts and medical alerts are backed by SQLite tables, synchronizing with backend REST endpoints whenever internet connectivity is restored.

Booking & Checkout Lifecycle

01 User selects pet profile & chooses clinical service category
02 Nearby clinics discovered via Google Maps location radius
03 Real-time slot reservation confirmed via Stripe payment authorization
04 Automated FCM push notifications & local calendar appointment sync
Engineering Challenges

Key Challenges Solved

Challenge: Dual Cart & Booking State Synchronization

Managing both physical merchandise (which requires warehouse inventory checks and shipping addresses) and time-based clinic bookings (which require slot holds and veterinary staff assignments) in a unified checkout flow risked transactional deadlocks.

Solution Implemented:

Architected distinct checkout coordinators that validate item inventory and appointment holds in isolated micro-steps before initiating a consolidated Stripe PaymentIntent.

Challenge: Offline Pet Health Records

Pet parents visiting veterinary hospitals frequently experience cellular dead-zones in clinical basements, making cloud-only medical profiles inaccessible during triage.

Solution Implemented:

Implemented an offline-first SQLite database schema storing encrypted local pet medical charts, prescription histories, and dietary notes with automatic cloud sync.
